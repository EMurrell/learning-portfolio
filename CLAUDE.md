# Learning Portfolio

## Project purpose

Personal learning portfolio for muscle-building in AI integrations and operational workflows. Captures what I'm learning as durable artifacts: writeups, eval notebooks, small bespoke tools, case studies.

Secondary purpose: documentation surface for future case studies and career artifacts. Content here should be portable, durable, and renderable on GitHub directly. **Plain markdown only, no tool-specific syntax.**

## Scope

In scope:

- Learning artifacts derived from active work (U7, Chintoka, WAS).
- Writeups, evals, small tools, case studies.
- Generalizable patterns and lessons.

Out of scope:

- U7 client work or client-identifying details.
- Chintoka commercial details, business logic, customer data.
- Anything that belongs in a source project repo.

Strict separation: this repo is the *learning output*, not the source projects. If something can't be sanitized to portable form, it doesn't belong here.

## Folder convention

    case-studies/
      YYYY-MM-slug/
        README.md     (writeup, narrative arc)
        artifacts/    (supporting files: configs, screenshots, exports)
        code/         (if there is runnable code)

Each case study is self-contained and portable. Should be liftable into a standalone repo or blog post without untangling.
